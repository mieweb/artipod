This fixture installs an `npm pack --ignore-scripts` tarball into a fresh temporary project. Both executable imports and TypeScript declaration checks use public package exports. The browser bundle uses the installed `dist` files, without checkout source aliases or `examples/` imports. Its disposable HTTP server and Chromium contexts require no SPA build or artipod server.

Run `npm run test:storage-consumer` from the repository root. Set `PLAYWRIGHT_MODULE_PATH` to an installed Playwright module and optionally `CHROMIUM_EXECUTABLE_PATH` to an existing Chromium executable. `npm run test:storage-consumer:node` runs only the packed Node consumer. The full runner also accepts `--browser-only` after building core.

Browser bundler prerequisites: `just-bash@3.4.2` retains imports of `constants`, `gzipSync`, and `gunzipSync` from `node:zlib` in its browser entry. This consumer maps only `node:zlib` to `zlib-browser.mjs`, a small adapter over the public `fflate` package supporting the compression levels and output limits used by that dependency. Its `zcat` byte formatting also expects global `Buffer`; this fixture supplies `buffer@6.0.3`. The shared scenario executes real shell `gzip` and `zcat` round trips. The adapter is not the full Node zlib API. No artipod module is aliased or replaced. These prerequisites belong to the current shell dependency; they are separate from storage encryption.

The shared scenario writes synthetic filenames, directories, contents, symlink targets, private application metadata, snapshot labels, refs, and layer indexes through a protected session and `createZenFsPod`. It restores a snapshot, closes and reopens storage, verifies exact data, rejects missing/wrong keys, and denies cached reads after key release. Forged contexts, ordinary adopted filesystems, and an unrelated plaintext OCI store supplied to a protected snapshot manager must be rejected before any initialization I/O. Explicit memory sessions must lose their data when closed; stale confined shells must reject access to replacement roots while fresh shells read normally.

Native backing inspection records bytes before every write and scans all final filenames and bytes. Browser inspection starts before the package bundle and observes OPFS writes (including writer streams), IndexedDB names/keys/values, and web storage. Temporary plaintext canaries prove the observers catch writes that disappear before final inspection. Raw OPFS and IndexedDB generation records must be ciphertext. The scan repeats after actual page reload.

`@artipod/core/storage/node` supports a dedicated local directory on filesystems providing exclusive file creation, atomic same-directory rename, and file/directory fsync. It exposes encrypted numeric records, not a plaintext native mount. Network filesystems and coordination across hosts are unsupported. A dead process leaves a writer lock that fails closed; an operator must verify no writer remains before deleting `.writer.lock`. This avoids portable Node's unsafe raced lock stealing. Native tests also cover interrupted reset ownership, corrupt/missing bootstrap data, and preservation of saved generations after failed opens.
